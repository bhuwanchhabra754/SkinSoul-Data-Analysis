This project presents an exploratory data analysis (EDA) of a skincare retail dataset. The analysis focuses on extracting meaningful business insights to support pricing, inventory, and promotional decisions. 
✅ Key Insights & Visuals:

1. Conducted brand- and product-level analysis of sales volume, profit, and inventory levels
2. Top selling products and brands by volume
3. Brands offering the highest average discounts
4. Finding the average profit by Brand
5. Actionable recommendations on pricing, promotions, and inventory.
6. Rationale for the product campaign to boost up the Sale.

📊 Tools used: Python, Pandas - For Analysis & Plotly, Matplotlib for Visualization
